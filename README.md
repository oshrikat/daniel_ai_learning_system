# Daniel AI Learning System v2.0

A personalized, accessible, gradual Web system empowering Daniel to master practical AI skills for work, social communication, and media.

## Key v2 Features
- **4-Step Active Learning:** Side-by-Side Demonstration -> Explanation -> Comprehension Quiz Check -> Hands-On Action.
- **10 Core Workplace & Practical Units:** Formal messaging, decoding workplace cues, media generation, media editing/refining, salary/payroll concepts, interview simulation, tabular data organization, and computer troubleshooting.
- **Async Adaptive Reinforcement:** Automatically identifies learning gaps and queues spaced reinforcement units in the background.
- **Hidden Admin Portal (`#admin`):** Protected with a PIN, featuring live progress analytics, curriculum management, and a shared notes board for Oshri and Dad.
- **AI Lesson Assistant with Live Preview:** Converse with AI to plan lessons, review the live interactive card, edit any field directly, and inject it into Daniel's curriculum.
- **Multi-Tier Fallback Chain:** Seamlessly falls back through Gemini -> Groq -> Local Ollama -> Built-in Offline Synthesizer.
- **100% Backward Compatibility:** Seamless silent migration preserves Daniel's existing v1 progress.
