תמיד פעיל ✅

מדריכי חיבור מהירים (שלב-אחר-שלב)

🔑 איך להוציא מפתח חינמי ל-Google Gemini תוך 60 שניות?
  1. היכנס לאתר Google AI Studio והתחבר עם חשבון Google.
  2. לחץ על Get API key בתפריט הצדדי.
  3. לחץ על Create API key והעתק את המחרוזת.
  4. הדבק אותה כאן למעלה בשדה של Gemini ולחץ "שמור הגדרות מפתחות".
⚡ איך להוציא מפתח חינמי ל-Groq (מהירות קיצונית)?
  1. היכנס לאתר Groq Console.
  2. לחץ על API Keys -> Create API Key.
  3. העתק את המפתח והדבק אותו בשדה של Groq למעלה.
💻 איך להפעיל מודל מקומי עם Ollama (ללא אינטרנט)?

התקן את Ollama מ-ollama.com, והרץ בטרמינל ollama run llama3. המערכת תפנה אוטומטית ל-http://localhost:11434.
